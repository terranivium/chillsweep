# Brand assets

Everything here is generated by **`build-icon.mjs`**. Edit that, not the SVGs.

```bash
node brand/build-icon.mjs
```

That one command regenerates the SVGs below, copies the logo to `src/logo.svg` (header, About and
favicon), and rebuilds the app icons in `src-tauri/icons/` with `tauri icon`.

| File | Purpose |
| --- | --- |
| `icon.svg` | The logo: an open fridge with leftovers on the shelves, on a dark full-bleed tile. Source for every app icon size. |
| `mark.svg` | The fridge alone, no tile, in `currentColor` for single-colour use. |

Colours are Catppuccin Mocha, the same values as Vocal Slice: a blue `#89B4FA` → mauve `#CBA6F7` mark on base `#1E1E2E`.
